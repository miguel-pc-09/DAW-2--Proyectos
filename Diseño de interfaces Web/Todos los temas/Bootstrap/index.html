Chuleta Bootstrap para el examen

1. CDN Bootstrap

Esto se pone siempre dentro del head para usar Bootstrap.

<link
href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/css/bootstrap.min.css"
rel="stylesheet"
/>

<script
src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/js/bootstrap.bundle.min.js"
></script>

2. Contenedores

Clase Qué hace
container Centra el contenido y deja márgenes laterales.
container-fluid Ocupa todo el ancho de pantalla. 
<div class="container">
    contenido
</div>

3. Grid Bootstrap

Bootstrap divide la pantalla en 12 columnas.

Clase Uso
row Crea una fila.
col-12 Ocupa toda la fila.
col-6 Media fila.
col-4 Un tercio. Perfecto para 3 tarjetas.
col-3 Un cuarto. 
<div class="row">

    <div class="col-4">
        tarjeta
    </div>

    <div class="col-4">
        tarjeta
    </div>

    <div class="col-4">
        tarjeta
    </div>

</div>
IMPORTANTE:
container → row → col

4. Márgenes y padding

Clase Qué hace
m-3 Margen general.
mt-5 Margen arriba.
mb-4 Margen abajo.
mx-auto Centra horizontalmente.
p-3 Padding interior.
g-4 Separación entre columnas.

5. Texto

Clase Qué hace
text-center Centra texto.
text-white Texto blanco.
text-dark Texto negro.
text-secondary Texto gris.
fw-bold Negrita.
fs-1 Texto enorme.
fs-4 Texto mediano/grande. 
<h1 class="text-center fw-bold fs-1">
    Título
</h1>

6. Fondos

Clase Color
bg-dark Oscuro.
bg-light Claro.
bg-primary Azul.
bg-success Verde.
bg-danger Rojo.
bg-body-tertiary Gris claro Bootstrap.
Si Bootstrap no tiene el color exacto:
style="background-color:#484e51"

7. Navbar

<nav class="navbar navbar-expand-lg"
style="background-color:#484e51">

    <div class="container-fluid">

        <div class="collapse navbar-collapse
        justify-content-center">

            <ul class="navbar-nav">

                <li class="nav-item">
                    <a class="nav-link text-white"
                    href="#">
                        Mamíferos
                    </a>
                </li>

            </ul>

        </div>

    </div>

</nav>
Clase Uso
navbar Crea navbar.
justify-content-center Centra enlaces.
text-white Texto blanco.
mx-3 Separación horizontal.
text-center NO centra elementos flex.
Para flex usar:

justify-content-center

8. Cards

<div class="card shadow p-3">

    <img
    src="./img/leon.jpg"
    class="card-img-top"
    alt="León"
    />

    <div class="card-body">

        <h5 class="text-center">
            León
        </h5>

    </div>

</div>
Clase Uso
card Crea tarjeta.
card-img-top Imagen arriba.
card-body Contenido interior.
shadow Sombra.
shadow-sm Sombra pequeña.
p-3 Espacio interior.

9. Flex útiles

Clase Uso
justify-content-center Centra horizontal.
justify-content-between Separa elementos.
align-items-center Centra vertical.

10. Sombras

Clase Uso
shadow-sm Sombra pequeña.
shadow Sombra normal.
shadow-lg Sombra grande.

11. Formularios

13. Errores típicos

Error Solución
Cards una debajo de otra Faltan cols.
Navbar no centra Usar justify-content-center.
Separación rara No mezclar col pequeñas con width manual.
Fondo claro raro navbar Quitar bg-body-tertiary.
Cards pegadas arriba Usar mt-5.
