## Cómo usar los ejercicios

Cada fichero sigue la misma estructura pedagógica:

1. **Cabecera** — unidad, tiempo estimado, dificultad, objetivo.
2. **Enunciado** — qué construir (con maqueta ASCII cuando aplica).
3. **¿Qué vas a aprender?** — checklist de conceptos.
4. **Cómo va a quedar** — boceto visual.
5. **Pasos numerados** — HTML/CSS comentado con el **por qué** de cada decisión.
6. **Trampas frecuentes** — comportamientos no obvios de CSS (margin collapse, especificidad, viewport, box-sizing, etc.).
7. **Código completo** — HTML + CSS finales, comentados.
8. **Cómo verificar responsive** — instrucciones de DevTools.
9. **Alternativas peores** — anti-patrones explicados (qué NO hacer y por qué).
10. **Errores comunes** — tabla Error · Causa · Solución.
11. **Lo que has aprendido** — recap final.

> **Recomendación**: haz primero el ejercicio básico de cada unidad, luego el intermedio. Antes del examen final, repasa los Pasos 4-8 de las unidades 4, 5 y 6 (donde tiene mayor peso el examen práctico).
