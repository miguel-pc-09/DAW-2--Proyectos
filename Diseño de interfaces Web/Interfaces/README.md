# Módulo 4 · Diseño de Interfaces Web

> CFGS Desarrollo de Aplicaciones Web · 2º curso

## Carpetas

- **`teoria/`** — apuntes + guía paso a paso (HTML5, CSS3, Flexbox, Grid, Bootstrap).
- **`simulacros/`** — test + explicaciones del test + `desarrollo/` (3 resoluciones paso a paso del examen).
- **`ejercicios/`** — primer de Interfaces y ejercicios de práctica adicionales.
- **`material/`** — `ej1/`, `ej2/`, `ej3/` con HTML/CSS/imágenes originales.

## Estructura del examen

- **Tiempo:** 90 minutos.
- **Test:** 15 preguntas opción múltiple.
- **Desarrollo:** elige **2 de 3** (3,5 puntos cada uno):
  1. Interface con CSS3 (panel de estadísticas).
  2. Interface con Bootstrap (página de producto: auriculares).
  3. Interface con Flexbox (formulario de registro).

## Temario del módulo (10 unidades)

Según `teoria.md`:

1. Introducción al diseño de interfaces web
2. HTML5: estructura, semántica y formularios
3. Introducción a CSS
4. CSS avanzado y Flexbox
5. Diseño de interfaces: layout y diseño responsive
6. Bootstrap
7. Multimedia: imágenes y SVG
8. Multimedia: audio, vídeo e integración
9. Contenido interactivo
10. Accesibilidad y usabilidad

## Plan de estudio

1. Lee `teoria.md` (unidad por unidad).
2. Repasa la sección de `pasos-desarrollo.md`.
3. Haz el test.
4. Reproduce los 3 ejercicios abiertos desde cero, mirando solo el screenshot del enunciado.
5. Compara tu solución con `material/ej1`, `ej2`, `ej3`.
